# Harbor Stream Blocker

A Manifest V3 WebView extension that Harbor installs into its own browser surfaces (`src-tauri/src/privacy.rs`) to block ads on Twitch and Kick.

| File                        | Source                                                                                                                                                                                                                                        |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `manifest.json`             | Harbor. Loads `rules.json` and injects `twitch-vaft.js` into Twitch pages at `document_start` in the `MAIN` world.                                                                                                                            |
| `rules.json`                | Generated by `node scripts/build-stream-blocker.mjs` from `src/lib/privacy/blocklist.ts`, scoped to the providers. Regenerate it rather than editing it.                                                                                      |
| `twitch-vaft.js`            | TwitchAdSolutions `vaft/vaft.user.js`, version 37.0.0, from [pixeltris/TwitchAdSolutions](https://github.com/pixeltris/TwitchAdSolutions) at commit `c51ef2fe8f667f9dc9216eb550924cf0d732ce27`, reformatted by `vp fmt` with no code changes. |
| `LICENSE-TwitchAdSolutions` | The MIT license that `twitch-vaft.js` ships under.                                                                                                                                                                                            |

To update the script, download `vaft/vaft.user.js` at the new upstream commit, replace `twitch-vaft.js`, run `vp fmt` on it, and update the commit and version above together with the `@version` assertion in `tests/stream-blocker.test.mjs`.
